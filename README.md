# Current community templates

Workflow templates for [Current](https://github.com/csprech/current) — the
open-source visual workspace for AI media workflows. The app reads this repo
directly; merging a pull request publishes a template.

## Submit a template

1. In Current: Project menu → **Publish to community…** (downloads a
   publish-ready JSON and opens this repo's upload page).
2. Upload your file into `templates/` — GitHub forks and opens a PR for you.
3. Add an entry for it in `index.json` (id, name, author, file, description).
4. A maintainer reviews the PR: the file must open cleanly in Current and
   describe itself honestly. Merged = published.

See the format details in
[Current's docs](https://github.com/csprech/current/blob/main/docs/community-templates.md).
